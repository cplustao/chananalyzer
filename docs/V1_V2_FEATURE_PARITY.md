# ChanAnalyzer v1 → v2 功能对账基线

## 用途

本表以重构前 Git 提交 `c8e33da` 为 v1 基线。重构验收不能只依赖 v2 自身测试；每项旧能力必须标记为“已迁移”“替代实现”“确认下线”或“待迁移”，其中前三类必须有验收依据或产品确认。

状态定义：

- `MIGRATED`：行为已经迁移，并有测试或可重复验收步骤。
- `REPLACED`：使用新方案替代，行为差异必须写明。
- `RETIRED`：经产品确认不再保留。
- `GAP`：旧版存在、v2 尚未闭环。

## 发布门禁

1. 新增或删除旧版对应能力时必须更新本表。
2. `GAP` 只有在实现并添加验收测试后才能改为 `MIGRATED`。
3. `REPLACED` 和 `RETIRED` 必须记录行为差异及产品确认，不能以“旧代码已删除”代替功能验收。
4. 个股 AI 的最低验收链路为：已结算交易日判断 → 必要时单股刷新 → 结构化模型输入 → 报告校验与持久化 → 页面自动显示结论或明确失败原因。
